RS256 Certificate Verification — Multi-threaded WASM

Proving RS256 (RSA-2048) certificate signatures entirely in-browser via multi-threaded WebAssembly (Web Workers + SharedArrayBuffer).

1

Load Certificate

Fetch test RS256 certificate input (circuit input JSON).

2

Generate Witness

Calculate circom witness in-browser using the RS256 witness calculator WASM (11MB).

3

Prove

Generate Spartan2 ZK proof from witness using multi-threaded WASM (rayon via wasm-bindgen-rayon).

4

Verify

Verify the Spartan2 proof in-browser via WASM.

Powered by Spartan2 + Hyrax ZK-SNARK prover running in multi-threaded WebAssembly via wasm-bindgen-rayon.

Circuit: rs256.circom — RSA-2048 certificate verification on secq256r1 field.
